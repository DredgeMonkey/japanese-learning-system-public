📘 Japanese Study Tracker: System Overview

🔧 Core Components
1. Dashboard
  • Current Phase (B3) → Sets the active phase
  • Phase Start Date (B4) → Drives date assignment logic
    • Days are linearly counted, not skipped. So Day 10 is always Day 10, even if you miss a day.
  • Lessons are user-editable — content per day is flexible
  • B25 → Email for reports
  • B27 → Sheet ID (controls which Learning Log is used)
  • B28 → Calendar ID (for optional event syncing)
  • 🧠 Update Dashboard → Refreshes metrics and auto-creates new log sheets if needed
2. Learning Log
  • Permanent study history — one sheet per phase
  • Auto-generated only when:
    • Dashboard B3 (Phase) is changed
    • B4 (Start Date) is set
    • Then you run 🧠 Update Dashboard
  • The system creates a new log (e.g., Learning Log 2, Learning Log 3, etc.)
  • Previous logs are preserved — each appears in your bottom sheet tabs
  • Populated via 📝 Quick Entry and 📘 Study Session
  • Feeds all dashboard metrics: streaks, hours, vocab, tags, difficulty
3. Master Lesson Plan
  • Organized by phase with columns: Day (A), Phase (B), Date (C), then your lesson content
  • Driven by Dashboard: B3 (Phase) + B4 (Start Date)
  • Run Assign Dates to Active Phase to fill in 90 sequential calendar days for the selected phase
  • Only columns A–C are overwritten — lesson content stays untouched
  • This mapping is required for syncing (tasks/calendar), but not required for logging
    • Day numbers are always sequential (1–90+), even if you miss a day — the calendar just keeps going
4. SmartPrompt Engine
  • 🎲 Click Get SmartPrompt → random suggestion based on mood
  • Does not affect logs, metrics, or syncing — purely for inspiration
5. Resource Guide
  • Tracks textbooks, videos, decks, etc.
  • Completely optional and standalone — doesn’t affect metrics
  • Helps you pair resources to study phases
🔁 How the System Flows
📝 Daily Logging
  • 📝 Quick Entry → fast log for vocab/kanji as well grammar and immersion
  • 📘 Study Session → detailed time, tags, difficulty
  • Data goes to active phase sheet
  • Metrics update automatically
🎬 Season Logger
    The Season Logger allows you to log entire anime seasons, TV shows, dramas, or other media content as single entries. These entries:
    • Contribute to total study hours
    • Do not count toward session count or average session time
    • Are tagged as Season Entry in the Learning Log
    • Default to "Media: Anime" as the tag, with optional type selection

    🎞️ What About Movies?
    Movies are short enough (~2 hours) that they can be logged using either the Quick Logger or Study Session Logger:
    • They count toward both total time and average session time
    • Recommended if you're studying with intent (e.g., subtitles, dictionary, note-taking)
    If you prefer to keep all media excluded from your averages, you may also log movies using the Season Logger — your system, your rules.
📅 Phase-Based Study Flow (Optional)
  • Set B3 (Phase) and B4 (Start Date) in Dashboard
  • Run Assign Dates to Active Phase to initialize your lesson calendar
  • Optionally extend the phase using the Extend Phase by +30 Days tool
  • Then you may choose to run:
    • Create Task Lists
    • Sync Tasks by chunk (Days 1–30, etc)
    • Sync Calendar Events
    • Syncing is optional and subject to Google API rate limits — the Learning Log is the true source of record.
📈 Extending a Phase
  • Click Extend Phase by +30 Days to append 30 new rows to the selected phase
  • The system locates the last dated row for the active phase and continues from there
  • Only columns A (Day), B (Phase), and C (Date) are filled in — you can add lessons manually anytime
  • Supports a total of up to 180 days per phase for syncing
    • Useful if your current phase isn’t finished yet but you want to continue logging or syncing seamlessly
📄 Auto-Creation of New Phase Logs
  • When you change B3 (Phase) and run 🧠 Update Dashboard:
  • System checks for a corresponding Learning Log X
  • If not found:
    • Copies the original Learning Log sheet
    • Clears data rows but keeps formatting
    • Renames to "Learning Log 2", "3", etc.
  • Metrics still stay continuous across phases
  • Keeps the spreadsheet clean and modular
🧹 Clean-Up & Re-Sync Tools
  • Wipe All Task Lists → Deletes all synced Google Task **lists** at the root level (which inherently deletes all associated tasks)
  • Clean Calendar Events → Deletes all synced study events from your linked Google Calendar
  • After wiping task lists:
    • You MUST re-run Create Task Lists
    • Then re-run Sync Tasks and/or Sync Calendar Events
  • Why this works best:
    • Google’s API imposes heavy caching & duplication restrictions
    • Trying to overwrite tasks/events in-place causes instability, duplicates, or partial syncs
    • Google also rate-limits “bulk delete + recreate” chains — delaying you more than this clean-slate flow
  • If deletion is incomplete due to API rate limits: simply re-run the clean-up tool — it’s safe
  • ✅ Your Learning Log and curriculum are untouched — syncing is just an optional integration layer
    • 🧠 After wiping, the system cannot remember your previous task completion — re-check any completed tasks manually in Google Tasks
⚠️ Important Notes
  • Task & Calendar Syncing is Optional — not required for core tracking
  • You must assign dates and create task lists before syncing tasks/events
  • You can extend phases in 30-day increments or by direct prompt entry — up to 180 days supported
  • Google Sheets stores timestamps in UTC — if you're selecting dates manually, use 🩺 Heal Session Anchors to clean up formatting or fix timezone mismatches caused by forward picking

🧰 Supplemental Tools
  • 🧽 Cleanup Tools → Wipe tasks/calendar before re-syncing
  • 🔁 Refresh Type Tags → Reapplies the formula in Column K to visually mirror your "Type" selections in Column B. Useful if tags go missing after manual entry or copy-paste.
  • 🔐 Real OAuth → Triggers Google's internal reauthorization handshake if you get access or sidebar errors. Run it, log out of your Google account, then log back in and reload the sheet.
  • 🧼 Format Dashboard Layout → Restores the Dashboard’s theme-based structure, header zones, colors, borders, and layout if things get visually broken.
  • 🎨 Theme Styling → Toggle Light/Dark + format fix
  • 📧 Email Reports → Daily & Weekly to B25 address
  • 🧪 Developer Tools:
    • Test Sheet ID (B27)
    • Test Calendar ID (B28)
  • 🎲 SmartPrompt → Dice-roll study inspiration
🧭 Final Guidance
  • Minimalist User: Just log & track — no syncing needed
  • Structured User: Assign dates + sync tasks, and visualize your progress calendar-style
  • Modular by Phase: Each new phase has its own log sheet — clean, efficient, expandable
  • Self-healing: Date weirdness? Session not syncing? Tools like 🩺 Heal Session Anchors and 🧪 Test Connections will always help realign
  • Flexible: Works for casual learners or JLPT prep warriors
